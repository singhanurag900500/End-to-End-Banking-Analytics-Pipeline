# 🏦 End-to-End Banking Portfolio & Customer Analytics Pipeline

## 📌 Project Overview
An end-to-end data analytics project analyzing customer demographics, deposit distributions, and loan portfolios using *Python, SQL, Excel, and Power BI*. The pipeline covers data cleaning, exploratory data analysis (EDA), statistical insights, and interactive executive reporting.

---

## 🛠️ Tech Stack & Skills
* *Data Processing & EDA:* Python (Pandas, NumPy)
* *Visualization & Statistics:* Matplotlib, Seaborn, Descriptive Statistics
* *Database & Querying:* SQL
* *BI Dashboard & Reporting:* Microsoft Power BI, DAX, Custom KPI Matrix, Excel
